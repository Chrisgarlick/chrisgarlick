# Case Studies — Client Zero

## Case Study 1: Kritano CMS

**Category:** Internal
**Slug:** kritano-cms
**Title:** Kritano CMS: Content Management Built from Scratch
**Result:** 12x faster content publishing
**Summary:** A purpose-built CMS that manages pages, blog posts, case studies, and proof metrics — built and run as Client Zero.
**Duration:** 4 weeks
**Tier:** Build + Retainer

### The Challenge

I needed a content management system that did three things: handled structured content (pages, posts, case studies, proof metrics), integrated with my delivery workflow, and served as living proof that I build real software — not just advice.

Off-the-shelf options did not fit. WordPress is bloated. Headless CMS platforms add external dependencies and monthly costs. I needed something lightweight, fast, and fully under my control. The site you are reading runs on it.

### What I Built

Kritano CMS is a headless content management system with collections for pages, articles, case studies, and proof metrics. Content is authored in an admin interface, stored as structured data, and rendered through a static site generator for near-instant page loads.

Key technical decisions:
- Structured collections for pages, articles, case studies, and proof metrics — each with enforced schemas and SEO fields.
- Rich text editing with support for headings, lists, code blocks, and inline links.
- Built-in SEO fields — title, meta description, Open Graph data, and canonical URL are part of every content record.
- No external dependencies beyond hosting. No third-party CMS subscription. No API rate limits.

### The Result

Publishing a new blog post or case study takes under 2 minutes from draft to live. Previously, content changes required code edits, git commits, and manual deploys — roughly 25 minutes per update.

The site loads in under 2 seconds on mobile. Lighthouse performance scores consistently exceed 90. Every page has structured data, unique meta descriptions, and proper heading hierarchy — all enforced by the CMS schema.

Kritano CMS is the proof that the tooling works. When a prospect asks "can you really build this?", the answer is the site they are looking at.

## Case Study 2: Integrated Delivery Workflow

**Category:** Internal
**Slug:** integrated-delivery
**Title:** Integrated Delivery: How One Developer Delivers Like a Team
**Result:** Solo developer delivering across 6 departments
**Summary:** A proprietary workflow system that executes structured project work across content, strategy, design, software, QA, and marketing — using AI where it fits, code where it doesn't.
**Duration:** Ongoing
**Tier:** Retainer

### The Challenge

The core constraint of solo operation is breadth. A single person can be deep in one discipline but shallow in others. To deliver complete projects — strategy, product specs, design systems, software, content, QA — I needed a system that maintained quality and consistency across every department without hiring a team.

### What I Built

I built a proprietary workflow system that executes structured project work across six departments: strategy, product, design, software, content, and QA. Each department operates with defined inputs, outputs, and quality standards. AI handles what AI is good at. The rest is databases, APIs, and code.

Key design decisions:
- Department-based architecture — each function has its own execution context, knowledge base, and output format.
- Dependency chains — downstream departments read upstream artefacts. Software reads the design system. Content reads brand guidelines. QA reads everything.
- Artefact consistency — every department produces versioned, structured outputs.
- Human-in-the-loop — I review, direct, and approve at every stage. The system executes. I make the decisions.

### The Result

I deliver complete projects — from strategy through to live, tested software — as a solo developer. The site you are reading was built this way: strategy, brand guidelines, design system, product requirements, content, code, and QA all produced through this workflow.

For clients, this means one point of contact, one person accountable, and delivery that moves faster than they expect from a solo engagement.
