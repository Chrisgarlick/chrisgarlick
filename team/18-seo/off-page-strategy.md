# Off-Page & Link Building Strategy

## Linkable Assets

1. **"State of AI in UK Professional Services" report** — Compile publicly available data into a single authoritative resource. Highest-value linkable asset for target sectors.
2. **AI Implementation Cost Calculator** — Interactive tool: input sector, team size, processes → estimated range + CTA for Kritano audit.
3. **Sector-specific AI readiness checklists** — PDF downloads. "Is Your Law Firm Ready for AI? 15-Point Checklist."
4. **Open-source Kritano CMS** — GitHub repo generates developer-community links. README links back to chrisgarlick.com.
5. **Process architecture diagrams** — Published in case studies. Embed chrisgarlick.com URL in images.
